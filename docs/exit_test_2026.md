### 1. Дискретизация

- Теорема: если спектр сигнала равен нулю при \(|f| > F_{\max}\), то при \(F_s > 2F_{\max}\) сигнал однозначно восстанавливается по отсчётам.
- \(F_s = 44{,}1\) кГц для \(F_{\max}=20\) кГц достаточно: \(44{,}1 > 40\), есть запас.
- Тон 30 кГц при \(F_s=44{,}1\) кГц: \(44{,}1 - 30 = 14{,}1\) кГц.
- \(\Delta f = 48000/1024 = 46{,}875\) Гц.
- При \(F_s = 2F_{\max}\) нужен идеальный фильтр; на практике нужен запас на переходную полосу и неидеальность фильтров.

### 2. ДПФ

- \(X[k] = \sum_{n=0}^{N-1} x[n]e^{-j2\pi kn/N}\), \(x[n] = \frac{1}{N}\sum_{k=0}^{N-1} X[k]e^{j2\pi kn/N}\).
- ДВПФ — бесконечная сумма, ДПФ — конечная; БПФ — быстрый алгоритм ДПФ.
- Тон в бине даёт один отсчёт (с учётом окна); между бинами — утечку на соседние бины.
- Окна снижают боковые лепестки, но расширяют главный лепесток.
- Zero-padding не улучшает истинное разрешение, только интерполирует спектр.
- Circular convolution считается через ДПФ; для линейной нужно дополнить до \(N \ge N_x + N_h - 1\).

### 3. QAM

- `1011`: I = `10` → +3, Q = `11` → +1, точка \((+3,+1)\).
- Gray снижает BER, потому что соседние символы отличаются одним битом; SER при этом не меняется.
- 64-QAM: 64 точки, 6 бит/символ, по 3 бита на I и Q.
- LLR — логарифм отношения правдоподобий; мягкие решения сохраняют уверенность демодулятора и дают выигрыш Витерби.

### 4. Кодер

- \((171,133)\): rate 1/2, \(K=7\), 6 ячеек памяти, 64 состояния.
- \(171_8 = 1111001_2\), \(133_8 = 1011011_2\).
- Единицы показывают, какие ячейки подключены к сумматору.
- Для \(K=3\), \(g_1=111\), \(g_2=101\), вход `1011`, начальное состояние `000`:
  
  ```text
  вход:    1     0     1     1
  регистр: 100   010   101   110
  выход:   11    10    00    01
  ```
  
  Итоговая последовательность: `11 10 00 01`.

### 5. Витерби

- Для \(K=3\) — 4 состояния: `00`, `01`, `10`, `11`.
- ACS: path metric + branch metric → сравнить две входящие ветви → оставить меньшую → запомнить survivor.
- Branch metric — штраф за один переход; path metric — сумма штрафов вдоль пути.
- Для \(K=7\): \(2^{K-1} = 2^6 = 64\) состояния.
- Traceback возвращает по сохранённым survivor к началу; типичная глубина — \(5K\).
- Нормировка не даёт метрикам расти без предела.
- Мягкие решения сохраняют больше информации, чем жёсткие; типичный выигрыш — около 2 дБ.

### 6. Обнаружитель

- \(\rho = \frac{|\sum x[n]p^*[n]|}{\sqrt{\sum |x[n]|^2 \sum |p[n]|^2}}\).
- Нормировка убирает зависимость от амплитуды; порог выбирается по допустимой вероятности ложной тревоги.
- CFO уменьшает пик; сегментированный поиск — это несколько корреляций с разными опорными частотами и выбор максимума.
- Для БПФ-корреляции заранее готовят спектр сопряжённо-обращённой преамбулы.
- Overlap-save применяется для блочной линейной свёртки; zero-padding убирает циклические хвосты.
- Хорошая преамбула: низкие боковые лепестки автокорреляции, устойчивость к CFO, достаточная длина, хорошая автокорреляция при сдвиге.

### 7. Сквозной тракт

- \(E_s/N_0 = E_b/N_0 \cdot \log_2 M \cdot R\).
- 16-QAM, \(R=1/2\): \(\log_2 16 = 4\), \(4 \cdot 1/2 = 2\), значит \(E_b/N_0 = E_s/N_0 - 3{,}01\) дБ.
- 64-QAM, \(R=2/3\): \(\log_2 64 = 6\), \(6 \cdot 2/3 = 4\), значит \(E_b/N_0 = E_s/N_0 - 6{,}02\) дБ.
- Для BER нужно много бит и хотя бы несколько десятков–сотен ошибок, иначе доверительный интервал слишком широк.

### 8. Диагностика BER

Типичные причины:

- неверная нормировка \(E_s/N_0\) или дисперсии шума;
- не скомпенсирована задержка RRC/согласованного фильтра;
- слишком короткое усечение RRC;
- ошибка в Gray-маппинге или порядке битов;
- нет тактовой/несущей синхронизации;
- клиппинг или неверная шкала созвездия;
- недостаточная статистика Монте-Карло;
- ошибка в soft/hard demapping.
